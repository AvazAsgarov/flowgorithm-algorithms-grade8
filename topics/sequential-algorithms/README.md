# Mövzu 1: Xətti Alqoritmlər (Sequential Algorithms)

> **The Lyceum of Digital Knowledge under Baku Higher Oil School** | 8th Grade Informatics  
> **Müəllim:** Avaz Asgarov

Bu bölmədə şagirdlər hər hansı şərt və ya dövr operatorlarından istifadə etmədən, addımların yuxarıdan aşağıya ardıcıl icra olunduğu **xətti alqoritmlər** ilə tanış olurlar.

## Tədris Hədəfləri

- Məsələnin şərtindən ilkin verilənləri (giriş) və axtarılan kəmiyyətləri (çıxış) təyin etmək.
- Müvafiq verilən tiplərini (`Integer`, `Real`) düzgün seçmək.
- İngilis dilində mənalı dəyişən adlarından istifadə etmək (`length`, `width`, `totalPrice`, `distance` və s.).
- İstifadəçiyə nə daxil etməli olduğunu aydın göstərən daxiletmə mesajları (`Output "..."`) tərtib etmək.
- Hesablanmış nəticələri aydın izahat mətni ilə sətirlər şəklində birləşdirərək (`&` simvolu ilə) ekrana çıxarmaq.
