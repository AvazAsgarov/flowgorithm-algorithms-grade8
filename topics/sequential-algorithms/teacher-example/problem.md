# Düzbucaqlı otağın sahəsi və perimetrinin hesablanması

### Məsələ

Düzbucaqlı formasında olan otağın döşəməsinin uzunluğu və eni məlumdur. İstifadəçidən bu ölçüləri daxil etməsi tələb olunur. Proqram daxil edilən ölçülərə əsasən otağın sahəsini və perimetrini hesablayıb istifadəçiyə aydın şəkildə təqdim etməlidir.

Düzbucaqlının sahəsi $S = \text{uzunluq} \times \text{en}$, perimetri isə $P = 2 \times (\text{uzunluq} + \text{en})$ düsturu ilə hesablanır.

### Giriş

İstifadəçi proqrama iki müsbət ədəd daxil edir:
1. Otağın uzunluğu (`length`) — metr vahidi ilə.
2. Otağın eni (`width`) — metr vahidi ilə.

### Gözlənilən çıxış

Proqram hesablanan dəyərləri müvafiq izahat mətni ilə iki sətirdə ekrana çıxarmalıdır:
- Otağın sahəsi (kv.m ilə).
- Otağın perimetri (m ilə).

### Nümunə

**Daxil edilən məlumatlar:**
```text
Otağın uzunluğunu daxil edin (metr):
6.5
Otağın enini daxil edin (metr):
4.0
```

**Gözlənilən nəticə:**
```text
Otağın sahəsi: 26 kv.m
Otağın perimetri: 21 m
```
